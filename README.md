# AIML Task 6 - K-Nearest Neighbors (KNN) Classification

## Project Overview

This project implements the K-Nearest Neighbors (KNN) classification algorithm using the Iris Dataset. The objective is to classify iris flowers into different species based on their morphological features. The project includes data preprocessing, feature normalization, K-value optimization, distance metric comparison, cross-validation, decision boundary visualization, and model evaluation.

## Objectives

* Understand instance-based learning using KNN.
* Perform feature normalization.
* Determine the optimal K value.
* Compare different distance metrics.
* Evaluate model performance using classification metrics.
* Visualize decision boundaries and learning curves.

## Dataset

The Iris Dataset contains measurements of iris flowers:

* Sepal Length
* Sepal Width
* Petal Length
* Petal Width

Target Classes:

* Iris-setosa
* Iris-versicolor
* Iris-virginica

## Results

The model successfully classified iris flower species with high accuracy. Feature normalization significantly improved performance, and the optimal K value was selected through experimentation.

## Conclusion

KNN is a simple yet powerful classification algorithm that performs well on small and medium-sized datasets. Proper normalization and K-value selection are critical for achieving optimal results.
