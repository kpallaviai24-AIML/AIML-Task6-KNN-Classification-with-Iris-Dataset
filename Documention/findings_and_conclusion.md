# Findings and Conclusion

## Findings

* The Iris dataset was successfully classified using the K-Nearest Neighbors (KNN) algorithm.
* Feature normalization improved model performance significantly.
* Different values of K were tested to determine the optimal number of neighbors.
* The best K value produced the highest classification accuracy.
* Cross-validation confirmed the stability and reliability of the model.
* Distance metric comparison showed the impact of Euclidean, Manhattan, and Minkowski distances on classification performance.
* The confusion matrix indicated strong classification capability across all iris species.
* Decision boundary visualization helped understand how KNN separates different classes.

## Conclusion

The K-Nearest Neighbors algorithm is a simple yet effective machine learning technique for classification problems. Through feature normalization, K-value optimization, and model evaluation, the classifier achieved high accuracy on the Iris dataset. The project demonstrates the importance of distance-based learning, proper preprocessing, and parameter tuning in machine learning applications.
